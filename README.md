# AudioAIOConverter

Egyszerű Windows 11 asztali alkalmazás audio fájlok konvertálásához.

## Technológiák
- Python 3.11+
- PySide6 (GUI)
- FFmpeg/FFprobe (audio feldolgozás)
- mutagen (metaadatok)

## Telepítés

```bash
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
